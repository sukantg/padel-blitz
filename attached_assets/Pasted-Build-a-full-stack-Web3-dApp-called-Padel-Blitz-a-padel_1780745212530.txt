Build a full-stack Web3 dApp called Padel Blitz — a padel sports micro-wagering app with an AI-generated superhero NFT player card and an AI coach. This is for a hackathon on Monad blockchain (EVM-compatible, high-throughput testnet).

- Smart contracts: Solidity (hardcode ABI in frontend)

- AI text: OpenAI API (gpt-4o) via OPENAI_API_KEY

- Chain: Monad Testnet (chainId: 10143, RPC: https://testnet-rpc.monad.xyz)

SMART CONTRACT — PadelBlitzWager.sol
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  struct Match {
    address player1;
    address player2;
    uint256 wagerAmount;
    uint8 state; // 0=Open, 1=Active, 2=Settled, 3=Cancelled
    address winner;
    string description;
    uint256 createdAt;
  }

Functions:
- createMatch(string description) payable → returns matchId
- joinMatch(uint256 matchId) payable → must send exact wagerAmount
- declareWinner(uint256 matchId, address winner) → onlyAdmin
- cancelMatch(uint256 matchId) → refunds player1
- getMatch(uint256 matchId) → returns Match struct
- storeNFT(string tokenURI) → stores base64 tokenURI on-chain per address

Events: MatchCreated, MatchJoined, MatchSettled, MatchCancelled
Fee: 1% taken on settlement, sent to admin
Admin = deployer address

TAB 1 — MY PLAYER NFT (hero feature, build this first)

SKILL SCORE CALCULATION (store everything in localStorage by wallet address):
- Player submits 5 sliders per session: Wins, Rallies, Smashes, Net Play, Consistency (each 0–10)
- Session score = wins×0.30 + rallies×0.20 + smashes×0.20 + netPlay×0.15 + consistency×0.15
- Cumulative skill score = rolling average of ALL past sessions (update on each save)
- Always displayed to 1 decimal place (e.g. 7.4 / 10)

TIER SYSTEM (drives image style + card theme):
  0.0–2.9  → Tier: "Rookie"      → style: scrappy underdog, casual padel kit
  3.0–4.9  → Tier: "Club Player" → style: confident club hero, blue kit
  5.0–6.9  → Tier: "Contender"   → style: fierce competitor, purple armour
  7.0–8.4  → Tier: "Elite"       → style: golden champion, glowing aura
  8.5–10.0 → Tier: "Legend"      → style: mythic god-tier, crimson cape

━━━━━━━━━━━━━━━━━━
AI IMAGE GENERATION (DALL-E 3) — THE CENTREPIECE
━━━━━━━━━━━━━━━━━━
When the player clicks "Save & evolve card", call POST /api/generate-nft on the backend.

Backend /api/generate-nft:
- Receives: { tier, skillScore, wins, rallies, smashes, netPlay, consistency }
- Calls DALL-E 3 with this dynamically constructed prompt:

  const tierStyles = {
    Rookie:      "a scrappy underdog padel player in casual sports kit, determined expression, gritty urban padel court background, comic book style",
    "Club Player": "a confident club-level padel superhero in a sleek blue outfit with a padel racket, dynamic pose, bright indoor court background, vibrant comic art style",
    Contender:   "a fierce padel warrior in purple futuristic armour holding a glowing padel racket, intense battle stance, dramatic stadium background, Marvel comic style",
    Elite:       "a golden champion padel superhero radiating a warm golden aura, wearing ornate gold-trimmed padel gear, triumphant pose, epic arena background, cinematic comic style",
    Legend:      "a mythic god-tier padel legend in a crimson flowing cape and dark armour, supernatural padel racket crackling with energy, cosmic court background, ultra-dramatic DC Comics style",
  };

  const prompt = `${tierStyles[tier]}.
    The player has a skill score of ${skillScore}/10.
    Their strongest stat is ${dominantStat} (score: ${dominantStatValue}/10).
    Incorporate visual cues for this strength into the character design.
    Full body portrait. No text or logos in the image.
    Style: bold comic book illustration, high contrast, dramatic lighting.
    Aspect ratio: portrait (tall).`;

- dominantStat = whichever of the 5 stats has the highest value
- API call:
    const image = await openai.images.generate({
      model: "dall-e-3",
      prompt: prompt,
      n: 1,
      size: "1024x1792",   // portrait
      quality: "standard",
      response_format: "url"
    });
    return { imageUrl: image.data[0].url };

- Cache the returned image URL in localStorage (by wallet + session index)
  so it does not regenerate on every render — only regenerate when
  "Save & evolve card" is clicked with new stat data

Two endpoints:

POST /api/generate-nft
  body: { tier, skillScore, wins, rallies, smashes, netPlay, consistency }
  → build DALL-E 3 prompt dynamically (see above)
  → call openai.images.generate (dall-e-3, 1024x1792, standard quality)
  → return { imageUrl: string }
  → wrap in try/catch; on error return { error: message }

POST /api/coach
  body: { description, skillScore, tier }
  → call openai.chat.completions.create (gpt-4o, max_tokens: 600)
  → strip markdown fences if present
  → JSON.parse and return
  → wrap in try/catch

OpenAI client init:
  import OpenAI from "openai";
  const openai = new OpenAI({ apiKey: process.env.OPENAI_API_KEY });
